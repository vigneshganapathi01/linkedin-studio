# LinkedIn Hook Extractor
Use when the owner or a client finds a viral post worth learning from. Study the hook, do not copy the post.

## Steps
1. Read the viral post from its URL (owner-provided or the owner's Chrome).
2. Identify which of the 20 canonical 2026 hook formulas it uses - anaphora, R.I.P., year-pivot, time-anchor, curiosity-gap, contrarian, comment-gate, emotional cold-open, named-gratitude, and 11 more.
3. Explain the exact structure and why it worked for that audience.
4. Return a blank template of that formula, mapped to the client's topic, so HOOK WRITER can build an original.

## Shape
Post URL -> formula name -> structure breakdown -> why it worked -> blank template on the client's topic.

## Rules
- Study, never copy. We produce the client's own version in their own voice.
- Keep a running "voices to watch" list per client.
- Full formula catalogue: read "LinkedIn Skills Reference/linkedin-hook-extractor" and "hook-formulas" in the Brain.
